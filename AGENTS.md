# Agriseco design workspace

Trước khi thêm hoặc sửa UI, token, component, trang demo, **đọc `arg-design-tokens/ui/AGENT-RULES.md`** và làm theo. Tóm tắt: token `--arg-*` cho mọi giá trị, icon Solar (Linear, Bold Duotone, Bold; CC BY 4.0), điều khiển cao 40px bo 13px, lề 20px, mỗi pattern một component, tiếng Việt, kiểm tra bằng Chrome headless. Sửa xong phải đồng bộ và build sang bản clone GitHub (xem mục 11 của AGENT-RULES.md).
