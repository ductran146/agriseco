## Dùng khi
Chọn một giá trị trong danh sách ngắn. Dùng `<select>` gốc để giữ bàn phím và trình đọc màn hình. Cần icon hoặc nhiều dòng trong mỗi lựa chọn thì dùng dropdown có `data-arg-select`.
## Class
| Class | Mô tả |
|---|---|
| `.arg-control.arg-select` + `.arg-select-native` | Select cao 40px. Icon cuối cùng trong khung luôn là `chevron-down` (đặt sát phải) |
| icon đứng trước `.arg-select-native` | Icon bên trái, nằm trong dòng bình thường |
| `--sm` `--xl` `--xxl` | Cao 32, 44, 48px |
## Trạng thái
Giống input: mặc định, hover, focus, lỗi, vô hiệu.
## JS
Không cần với `<select>` gốc. Bản menu tuỳ biến xem mục Dropdown.
## Phụ thuộc
`field.css`, `icon.css`.
