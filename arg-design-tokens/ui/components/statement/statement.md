## Dùng khi
Danh sách giao dịch theo kỳ: lệnh đã bán trong sao kê lãi lỗ, giao dịch tiền trong sao kê tiền.
## Class
| Class | Mô tả |
|---|---|
| `.arg-stmt-list` | Danh sách (`ul`), thẻ cách nhau 12px |
| `.arg-stmt` | Một thẻ nền `--arg-ui-background-background`, bo `--arg-radius` |
| `__head` `__type` | Ngày bên trái, loại giao dịch bên phải (nhãn nền đen, chữ trắng), kẻ ngăn dưới |
| `__title` | Nội dung giao dịch |
| `__rows` `__row` | Các khoản (`dl`): nhãn trái, giá trị phải; `dd.arg-up` ghi có hoặc lãi, `dd.arg-down` ghi nợ hoặc lỗ |
| `__more` | Nút mũi tên (Collapse) mở phần Phí, Thuế |
## Phụ thuộc
Accordion (Collapse), Button (`.arg-icon-btn`).
