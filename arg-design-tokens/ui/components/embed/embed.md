## Dùng khi
Khung tỉ lệ cố định cho video hoặc iframe.
## Class
| Class | Mô tả |
|---|---|
| `.arg-ratio` | Khung tỉ lệ, 16:9 mặc định |
| `--21x9` `--16x9` `--4x3` `--1x1` | Tỉ lệ |
| `.arg-ratio__inner` `.arg-video` | Khung mô phỏng có nút phát |
Đặt `<iframe>`, `<video>` hoặc `<embed>` trực tiếp trong `.arg-ratio`, nó tự phủ kín khung.
