## Dùng khi
Thông điệp quảng bá hoặc giới thiệu ở đầu trang mà người dùng có thể tắt.
## Class
| Class | Mô tả |
|---|---|
| `.arg-promo` | Thẻ nền xám nhạt |
| `__media` | Ô icon gradient 48px |
| `__body` `__title` `__text` | Nội dung |
| `__close` | Nút đóng, đặt `data-arg-dismiss=".arg-promo"` |
## JS
Dùng chung script của Alert. Khi đóng, thẻ thu chiều cao về 0, mờ dần và triệt khoảng cách để các khối dưới trượt lên (không animation khi bật giảm chuyển động).
