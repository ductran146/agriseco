## Dùng khi
Gắn nhãn trạng thái ngắn hoặc bộ đếm cạnh một phần tử khác.
## Class
| Class | Mô tả |
|---|---|
| `.arg-badge` | Nhãn xám, cao 22px |
| `--orange` `--blue` `--purple` `--yellow` `--success` `--error` | Màu Weak |
| `--solid` `--outline` `--brand` | Nền đặc, chỉ viền, gradient nút chính |
| `--up` `--down` `--ref` | Màu giao dịch |
| `--buy` `--sell` | Chiều lệnh Mua, Bán (màu nút Mua, Bán, nền 12%), ví dụ giao dịch nội bộ |
| `--pill` | Bo tròn |
| `.arg-count` | Bộ đếm đỏ; đặt trong `.arg-indicator` để nằm góc phần tử |
