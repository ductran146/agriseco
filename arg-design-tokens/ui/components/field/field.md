## Dùng khi
Lớp nền chung cho input, select, textarea. Không dùng riêng.
## Class
| Class | Mô tả |
|---|---|
| `.arg-field` | Khối nhãn + control + gợi ý |
| `.arg-label` `.arg-help` | Nhãn và dòng gợi ý hoặc lỗi |
| `.arg-control` | Khung viền cao 40px |
| `--sm` `--xl` `--xxl` | Cao 32, 44, 48px |
| `.is-error` `.is-success` (trên `.arg-field`) | Trạng thái kiểm tra |
