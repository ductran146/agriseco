## Dùng khi
Ảnh trong nội dung và avatar người dùng.
## Class
| Class | Mô tả |
|---|---|
| `.arg-img` | Co giãn theo khung (`max-width:100%`) |
| `--rounded` `--circle` `--thumb` | Bo góc, tròn, có viền |
| `.arg-figure` | Ảnh kèm chú thích |
| `.arg-avatar` | Avatar 40px, gradient nút chính |
| `--xs` `--sm` `--lg` `--xl` | 24, 32, 56, 72px |
| `--gray` `--blue` `--purple` `--square` | Màu và hình |
| `.arg-avatar-group` | Chồng nhiều avatar |
