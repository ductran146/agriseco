## Dùng khi
Đầu vùng đặt lệnh để chọn mã và xem trạng thái phiên.
## Class
| Class | Mô tả |
|---|---|
| `.arg-symbol` | Hàng ngang |
| `__search` `__code` | Icon tìm kiếm 24px, mã (Title 3 đậm) |
| Badge, `.arg-icon-btn` | Nhãn sàn và nút thông tin (xem Badge, Buttons) |
| `.arg-live` `--closed` | Trạng thái phiên căn phải: `__dot` xanh (đang giao dịch) hoặc vàng (`--closed`) |
