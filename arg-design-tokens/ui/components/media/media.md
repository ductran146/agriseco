## Dùng khi
Avatar hoặc ảnh nhỏ nằm cạnh nội dung: bình luận, tin tức, danh sách người dùng.
## Class
| Class | Mô tả |
|---|---|
| `.arg-media` | Hàng gốc |
| `--center` `--end` | Căn giữa dọc, đảo bên phải |
| `__body` `__title` `__text` `__actions` | Nội dung |
| `__thumb` | Ảnh nhỏ 4:3 |
| `.arg-media` lồng nhau | Trả lời bình luận |
