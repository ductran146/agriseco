## Dùng khi
Đầu màn Thêm hoặc màn cài đặt: cho người dùng biết đang đăng nhập bằng tài khoản nào.
## Class
| Class | Mô tả |
|---|---|
| `.arg-profile` | Thẻ nền cam nhạt 8%, bo `--arg-radius-lg`; đặt kèm `.arg-brandmark--soft.arg-brandmark--corner` để có hình chìm |
| `__avatar` | Avatar tròn 56px, gradient thương hiệu, chữ cái đầu trắng |
| `__body` `__name` `__sub` | Tên (Title 2 đậm) và dòng phụ số tài khoản |
Họ tên là dữ liệu mẫu, chưa phải khách hàng thật.
