## Dùng khi
So sánh giá trị theo phiên hoặc theo kỳ, có cả tăng và giảm.
## Class
| Class | Mô tả |
|---|---|
| `.arg-bars` | Lưới theo `--n` cột, cao 220px |
| `.arg-bar` | Một cột gồm `__half--pos` (nửa trên), `__half--neg` (nửa dưới, viền là đường 0) và `__date` |
| `__fill` `--up` `--down` | Thân cột, `--v` là phần trăm so với giá trị lớn nhất |
| `__val` | Nhãn giá trị |
| `--dense` | Từ 8 đến 10 cột: thân cột 16px, nhãn cỡ Label 2 |
