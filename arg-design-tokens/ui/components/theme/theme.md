## Dùng khi
Danh sách chủ đề (nhóm ngành) ở tab Chủ đề và phần tên, thay đổi ở đầu trang chi tiết chủ đề.
## Class
| Class | Mô tả |
|---|---|
| `.arg-theme-list` | Danh sách (`ul`), các hàng cách nhau 16px |
| `.arg-theme` | Một hàng 3 cột: ảnh, tên, badge. Đặt `--tint` (màu nền ảnh) trên `li` để ảnh chưa tải vẫn có nền |
| `__img` | Ảnh vuông 64px bo `--arg-radius` |
| `__id` `__name` `__sub` | Liên kết (vùng bấm phủ cả hàng): tên tối đa 2 dòng, dòng phụ "x/y mã tăng" |
| `.arg-badge` | Badge % trung bình (`--up` `--down` `--ref`), kèm icon mũi tên 12px |
| `.arg-theme-head` `__meta` `__chg` | Đầu trang chi tiết: tên, thay đổi (icon `trend-up` hoặc `trend-down`, màu `.arg-up` `.arg-down`) và số mã |
